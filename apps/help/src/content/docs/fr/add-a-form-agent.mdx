Un **agent de formulaire** aide un utilisateur à **remplir un formulaire par la
conversation**. Au lieu d'afficher des champs statiques, il pose les questions une à
une et collecte des **réponses structurées** conformes à un schéma que vous
définissez — combinant l'expérience d'un chat avec la sortie structurée d'un
[agent d'extraction](/fr/add-an-extraction-agent).

Les agents appartiennent à votre **espace de travail** et se créent depuis la carte
**Nouvel agent** de la vue d'ensemble (ou le **+** à côté d'**Agents** dans la barre
latérale gauche). C'est le choix du type **Formulaire** qui transforme l'agent en
formulaire guidé.

## Comment fonctionne un agent de formulaire

Le choix **Formulaire** crée un **agent conversationnel** avec l'outil **Remplissage de
formulaire** activé. Vous définissez les **champs à collecter** dans **Outils**, sous
**Remplissage de formulaire** (par exemple `full_name` et `email`), un **Message
d'accueil** par lequel l'agent commence, et des **Instructions** décrivant comment il
doit guider l'utilisateur. Sur la page de l'agent et dans son éditeur, l'agent
apparaît comme un agent conversationnel.

Une fois créé, l'agent s'ouvre dans son **éditeur**, une page à part entière. Son
menu de gauche affiche **Retour**, le nom de l'agent avec *Modifier l'agent
conversationnel*, puis les sections d'un agent conversationnel : **Général**,
**Modèle**, **Sources**, **Outils** et, quand votre espace de travail a des
catégories, **Catégories de conversation**. Sous **Plus** viennent **Serveurs MCP**,
**Orchestration** et **Intégration** quand ils sont activés. En bas, **Gérer les
versions** ouvre l'[historique des versions](/fr/agent-version-history). Voir
[Ajouter un agent conversationnel](/fr/add-a-conversation-agent) pour chaque section.

**Il n'y a pas de bouton Enregistrer.** Chaque modification s'enregistre d'elle-même
dans le **brouillon** de l'agent, un court instant après votre dernière frappe. Le
statut en haut à droite affiche **Enregistrement…**, puis **Brouillon enregistré**. Un
nouvel agent atteint ses utilisateurs une fois le brouillon enregistré comme version.

## Étape par étape

### 1. Ouvrir la boîte de dialogue Nouvel agent

Sur la vue d'ensemble de l'espace de travail, repérez la carte **Nouvel agent** et
cliquez sur **Créer** (vous pouvez aussi utiliser le **+** à côté d'**Agents** dans
la barre latérale gauche).

### 2. Choisir le type Formulaire

Dans la boîte de dialogue **Nouvel agent**, sous **Type d'agent**, sélectionnez
**Formulaire**. Ce choix crée un agent conversationnel déjà prêt à remplir un
formulaire : instructions par défaut, outil **Remplissage de formulaire** activé et
formulaire d'exemple.

### 3. Nommer l'agent et le créer

Saisissez un **Nom** (au moins 3 caractères) dans le champ **Nom**, puis cliquez sur
**Créer**. Votre agent est créé et son éditeur s'ouvre sur **Général**.

### 4. Régler l'essentiel dans Général

Définissez :

- le **Nom** : comment l'agent apparaît dans votre espace de travail ;
- le **Message d'accueil** : le premier message envoyé par l'agent au début d'une
  conversation. Le compteur à côté du libellé indique sa longueur et son maximum
  (2 000 caractères) ;
- les **Instructions** : comment l'agent doit guider l'utilisateur dans le
  formulaire. Le compteur à côté du libellé indique leur longueur.

Les deux zones de texte s'agrandissent avec leur contenu. Une fois que l'agent a une
version publiée et que vous modifiez les instructions, un bouton **Mode avancé** à
côté d'**Instructions** montre les différences avec les instructions publiées, et vous
pouvez les modifier directement dedans. Chaque modification s'enregistre d'elle-même :
le statut en haut à droite affiche **Brouillon enregistré**.

### 5. Choisir le modèle dans Modèle

Cliquez sur **Modèle** dans le menu. Sous **Génération des réponses**, choisissez le
**Modèle** qui pilote l'agent et ses options, comme la **Température** (une valeur
basse donne des questions plus stables et prévisibles).

### 6. Construire le formulaire dans Outils

Cliquez sur **Outils**. L'interrupteur **Remplissage de formulaire** est activé.
Dessous : *Définissez les champs du formulaire que l'agent doit remplir. L'ordre des
champs est l'ordre dans lequel l'agent pose ses questions.* Construisez les champs
**visuellement**, sans JSON. Cliquez sur **Ajouter un champ** et, pour chaque champ,
définissez :

- **Nom du champ** : la clé sous laquelle la réponse est stockée (par ex.
  `full_name`).
- **Type** : **Texte**, **Nombre**, **Oui / Non**, **Liste** ou **Choix**. **Nombre**
  propose une plage min/max optionnelle, et **Choix** permet de définir les valeurs
  autorisées.
- **Description** : la question ou l'indice que l'agent utilise pour demander ce
  champ.
- **Obligatoire** : activez-le pour les réponses requises.

Supprimez un champ avec son icône **corbeille**. Pour maîtriser l'ordre des
questions, activez **Poser les questions dans cet ordre** et **glissez** les lignes
dans l'ordre voulu ; désactivez-le pour laisser l'assistant choisir l'ordre.

### 7. Modifier le formulaire en JSON

Besoin d'un contrôle plus fin ? Cliquez sur **Mode avancé** (en haut à droite de la
liste des champs) pour éditer le JSON brut, et sur **Éditeur visuel** pour revenir.

### 8. Enregistrer le brouillon comme version

Quand le brouillon est prêt, cliquez sur **Gérer les versions** en bas du menu (ou sur
le statut **Brouillon enregistré**). Le brouillon est sélectionné : cliquez sur
**Enregistrer la version**, nommez-la si vous le voulez, et cliquez à nouveau sur
**Enregistrer la version**. Les utilisateurs parlent désormais à cette version. Voir
[Historique des versions](/fr/agent-version-history).

## Conseils

- Gardez des **descriptions** de champs claires : l'agent s'en sert pour formuler
  chaque question et pour décider quoi enregistrer.
- Utilisez **Poser les questions dans cet ordre** quand la séquence compte (par ex.
  demander un nom avant une préférence) ; laissez-le désactivé pour que l'agent
  s'adapte.
- Le **Message d'accueil** donne le ton ; rédigez-le dans la langue de vos
  utilisateurs.
- Utilisez une **Température basse** (par exemple `0.2`) pour que l'agent pose des
  questions cohérentes plutôt que d'improviser.
- Les réponses déjà collectées sont conservées d'un tour à l'autre : une valeur que
  l'agent ne connaît pas n'efface jamais une réponse enregistrée. Pour corriger une
  réponse, l'utilisateur donne simplement la nouvelle valeur.
- Tout agent conversationnel peut collecter un formulaire : activez le **Remplissage
  de formulaire** dans ses **Outils**.

## Dépannage

- **Le bouton Créer est désactivé.** Le **Nom** doit comporter au moins 3 caractères.
- **Je ne vois pas le type de champ dont j'ai besoin.** L'éditeur visuel couvre
  **Texte**, **Nombre**, **Oui / Non**, **Liste** et **Choix** ; utilisez le **Mode
  avancé** (JSON brut) pour des **objets imbriqués**.
- **L'agent pose les questions dans le mauvais ordre.** Activez **Poser les questions
  dans cet ordre** et glissez les champs dans la séquence voulue.
- **Je ne vois pas les champs du formulaire.** Ouvrez **Outils** et vérifiez que le
  **Remplissage de formulaire** est activé : les champs n'apparaissent que dans ce
  cas.
- **Le statut affiche Modifications non enregistrées.** Une valeur n'est pas valide,
  et le champ indique pourquoi, ou l'enregistrement a échoué, et un encadré rouge
  au-dessus des champs, **Cette modification n'a pas pu être enregistrée**, en donne
  la raison. Corrigez la valeur, ou cliquez sur **Réessayer**.
- **Les utilisateurs voient encore l'ancien formulaire.** Vos modifications sont dans
  le brouillon. Cliquez sur **Gérer les versions**, puis sur **Enregistrer la
  version**.
