Every agent keeps a **version history** of its settings. The changes you make in the
agent editor save by themselves to a **draft**. Users keep talking to the published
version until you **save the draft as a version**. The history lets you see what
changed, publish the draft, and **restore** an older version if a change did not work
out.

It is available on **every agent** (conversation, extraction, form). Open it from the
**Manage versions** button at the bottom of the agent editor's menu, whatever section
you are on.

## Draft and versions

- **The draft.** Every change in the editor's sections (**General**, **Model**,
  **Sources**, **Tools**, **Conversation categories**, **Output**) saves by itself to
  the draft, a moment after you stop typing. There is no Save button. The status at
  the top right of the editor reads **Saving…**, then **Draft saved**. If you undo
  your changes and the draft matches the published version again, the draft is
  removed.
- **A version.** **Save version** turns the draft into a numbered version. The agent
  then runs with it: users, the app and the embed talk to this version. Your next
  change starts a new draft.
- **What is tracked.** The comparison shows, field by field, what changed between two
  versions: for example **Instructions**, **Greeting**, **Model**, **Model options**,
  **Answer source**, **Embedding model**, **Priority calls**, **Form filling**,
  **Output JSON Schema**, **Prompt variables** and the follow-up question settings.
- **Not tracked.** **MCP Servers**, **Orchestration** and **Embed** are not part of
  the draft. They apply to the agent in production as soon as you save them, so they
  have no versions. The same goes for three settings inside the draft sections: the
  **Document Tags** and the **Resource libraries** of **Sources**, and the ticked
  **Conversation categories**. They save by themselves like the rest, but on the agent
  itself: they apply at once and a restore does not change them.

Restoring never deletes anything: it copies an old version's settings into a **new**
version, which becomes the current one.

## Step by step

### 1. Open the version history

In the agent editor, click **Manage versions** at the bottom of the left menu. You can
also click the status at the top right of the editor: **Draft saved** when the agent
has a draft, or **Version *n* · published** when it has none.

### 2. Browse the versions

**Version history** opens full screen, with the description *Browse, compare and
restore previous settings of* your agent. The left column lists every version,
**newest first**. Each row shows **Version *n***, its name and description if it has
any, and when it was saved. The draft carries a **Draft** badge, and the version the
agent runs with carries a **Current** badge. When the agent has a draft, it is
selected first. Click a row to select another version.

### 3. Choose what to compare

Above the comparison, pick what the selected version is compared with:

- **Changes in this version**: what changed between the selected version and the one
  just before it.
- **Compare with current**: the difference between the selected version and the
  published version.
- **Compare with draft**: the difference between the selected version and the draft.
  It only shows when the agent has a draft.

An option is greyed out when it does not apply to the selected version. A caption
tells you which two versions you see, for example *Showing changes from version 2 to
version 3.* With a single version, you see **Only one version**. When two versions
are identical, you see **No differences**.

### 4. Read the diff

A line names every field that changed, for example *2 changed fields:*
**Instructions** **Greeting**. Click a field name to jump to its diff. Each diff shows
the removed text in red and the added text in green.

### 5. Save the draft as a version

Select the version with the **Draft** badge. Click **Save version** at the top right
of the comparison.

### 6. Name the version and confirm

The **Save version *n*?** dialog explains: *Version n becomes the settings this agent
runs with. Later changes start a new draft version.* Fill in, if you wish:

- **Version name** (placeholder *Name this version*). **Optional**.
- **Version description** (placeholder *Describe what changed in this version*).
  **Optional**.

Click **Save version**. The version loses its **Draft** badge and gets the **Current**
badge. The editor status now reads **Version *n* · published**.

### 7. Restore an older version

Select an older version in the list, then click **Restore this version** at the top
right of the comparison. The button is greyed out on the newest version: there is
nothing to restore.

### 8. Confirm the restore

The **Restore version *n*?** dialog explains that *The settings of version n will be
copied as a new version and become the current settings. No version is deleted.*
Click **Restore this version** to apply it, or **Cancel**. The editor reloads with the
restored settings.

## Tips

- Change the agent freely: users only see your changes once you click **Save
  version**.
- Test the draft before you save it as a version: in the playground of the agent page,
  the version selector can run the draft.
- Give important versions a **Version name**, such as *Shorter answers*: you find
  them faster in the list.
- Use **Compare with current** to review everything that changed since the published
  version before you save the draft.
- Restoring is safe: it creates a new version, so you can always restore forward
  again.

## Troubleshooting

- **I don't see Manage versions.** It is at the bottom of the agent editor's left menu.
  On a narrow screen, open the menu with the sidebar button first.
- **The panel says "Only one version".** The agent has a single version. There is
  nothing to compare yet.
- **My draft disappeared.** You undid your changes, so the draft matched the published
  version and was removed. The status reads **Version *n* · published**.
- **Users still get the old answers.** Your changes are in the draft. Open the
  history, select the draft and click **Save version**.
- **Restore is greyed out.** You selected the newest version. Pick an older one.
- **A change broke the agent.** Open the history, find the last good version, and
  **Restore** it. Nothing you saved is lost.
